# Innecesariamente Necesario

**Web:** https://prelabhomework.github.io/innecesariamente-necesario/

## Qué editar

- `assets/config.js` . tu email, Instagram y PayPal
- `assets/products.js` . los productos (copia un bloque y cambia los datos)
- `assets/brand.css` . los colores (bloque `:root` al principio)
- Fotos de producto: cuadradas, en `assets/img/`

Si añades un producto con otra marca (por ejemplo `marca: "Sama"`), su filtro aparece solo.

## Pedidos

La clienta hace el carrito y lo envía por email o por DM. Tú confirmas y le mandas el pago por PayPal.

## Actualizar la web

Cambio pequeño: abre el archivo en GitHub, pulsa el lápiz y **Commit changes**.

Versión nueva: copia el **contenido** del zip (no la carpeta) en tu carpeta del repo y ejecuta:

```
git add .
git commit -m "cambio"
git push
```

Espera un minuto y recarga con Ctrl+F5.
